### ALGO-000034: Superpolynomial general formula lower bounds
- **Subfield:** Boolean circuit and formula complexity
- **Open:** Find an explicit function in P requiring superpolynomial-size unrestricted Boolean formulas.
- **Status:** Open for decades. Strong polynomial lower bounds and exponential bounds for restricted formula models are known, but unrestricted superpolynomial bounds remain elusive.
- **Type:** impossibility
- **Why:** Would prove that reusing intermediate computations can provide more than a polynomial advantage.
- **Key works:** Håstad (1998), *The Shrinkage Exponent of de Morgan Formulas Is 2*; Hoza (2024), circuit-complexity course materials.
- **Related:** Mathematical logic—size of propositional expressions; programming languages—benefits of sharing versus tree expansion.
